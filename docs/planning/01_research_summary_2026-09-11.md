## Rationale for Selections

### Priority 1 Topics (Week 1)
1. **Inline Suggestions and Ghost Text** - Foundational feature; users encounter this immediately upon enabling Copilot. Understanding how to read and interact with ghost text is essential before any other Copilot feature.

2. **Copilot Chat Interface Basics** - The chat panel is the primary conversational interface. Users need to know where it is, how to open it, and basic interaction patterns before using advanced features.

### Priority 2 Topics (Week 2)
3. **Slash Commands Overview** - Slash commands (/tests, /explain, /fix, /docs) are the most efficient way to get specific outputs from Copilot Chat. Essential for productive workflows.

4. **Context Management with @ Symbols** - Understanding @workspace, @file, @terminal, and other context selectors dramatically improves Copilot's relevance and accuracy. This is the bridge between basic and intermediate usage.

### Priority 3 Topics (Week 3, Early)
5. **Accepting and Rejecting Suggestions** - Keyboard shortcuts and workflows for efficiently handling inline suggestions. Often overlooked but critical for speed.

6. **Natural Language to Code in Comments** - Writing comments that trigger useful suggestions is a core Copilot skill. Teaches prompt engineering fundamentals.

### Priority 4 Topics (Week 3, Late)
7. **Copilot Chat Modes and Perspectives** - Agent mode, Ask mode, and different perspectives (workspace, user, etc.) are more advanced concepts that build on earlier topics.
